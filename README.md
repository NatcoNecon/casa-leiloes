# Casa de Leilões

Sistema para gerenciamento de uma casa de leilões, permitindo cadastro, listagem e venda de itens.

Tecnologias utilizadas: Java e MySQL.

# Sistema de Casa de Leilões

**Status do projeto:** Em desenvolvimento

**Tecnologias aplicadas:**
- Java
- MySQL
- NetBeans
- Git / GitHub

**Time de desenvolvedores:**
- Nathan Vieira Campos da Silva

**Objetivo do software:**
Desenvolver um sistema desktop para gerenciamento de uma casa de leilões, permitindo o cadastro de produtos, controle de vendas e consulta de produtos disponíveis e vendidos.

**Funcionalidades do sistema (requisitos):**
- Cadastrar novo produto (nome, valor, status).
- Listar todos os produtos cadastrados.
- Vender um produto informado pelo ID.
- Consultar produtos vendidos.
- Navegação entre telas (cadastro, listagem, vendas).
- Integração com banco de dados MySQL.
